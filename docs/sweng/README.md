# PaperMesh project documentation

The Pflichtenheft and project plan are available in [PR #1](https://github.com/LenThava/PaperMesh/pull/1), first opened on 9 October and revised for the 27 October milestone following Giovanni's feedback. Development will use the private [LenThava/jabref_hs26](https://github.com/LenThava/jabref_hs26) course fork, initially at main revision `c705647a4e2c37ae9f608cdd959d98c88a0fde44`.

## Workflow

- `main` contains the project overview.
- `project` is the documentation review target in this repository.
- `requirements` was created from `project` and contains the working Pflichtenheft and project plan.
- Review the requirements documents through a pull request from `requirements` into `project`, with the assigned supervisor as reviewer.
